# 考试 RAG 切块质量隔离 A/B 报告

**日期：** 2026-07-21
**范围：** 高考英语、2026 数学 DOCX、2026 数学 PDF、2025 数学 DOCX
**结论：** 不把本轮 `auto` 配置推广到正式知识库。

## 评测边界

- 4 组 baseline/candidate 均使用隔离知识库副本；正式知识库未重切、未修改配置。
- baseline 固定为 `legacy`，candidate 使用修复配置透传后的 `auto`。
- 其他参数保持一致：`chunk_size=512`、`overlap=80`、父块 `4096`、子块 `384`、开启父子块。
- 金标文件为 [2026-07-21-exam-rag-chunking-cases.json](./2026-07-21-exam-rag-chunking-cases.json)，共 25 条稳定检索短语：英语 9 条、2026 数学 8 条、2025 数学 8 条。

## 归因与限制

- `auto` 已真实生效：candidate 的 processing span 同时记录 requested strategy、parent tier、child tier counts 和回退原因，不再静默按空 strategy 走 legacy。
- 英语 E01 金标 “Los Angeles Chargers v Los Angeles Rams” 在两组中均未命中；修复后 UI 正确显示“未命中”，不再显示“无检索金标”。
- 表中初始运行发生在动态关联实现之前；当时克隆后 Chunk ID 改变，题组引用仍指向正式知识库，因此 `structured_resolution_rate=0` 是关联重建限制，不是 chunker 回归。后续只读动态关联验收已达到 0.96。
- 表中初始运行提交时只设置检索短语金标，因此当时的 `answer_hit_rate=0` 不能用于比较切块效果。当前金标文件已补齐答案短语，最终动态关联运行的答案覆盖率为 0.84。
- 浏览器验证覆盖 1440x1000 和 390x844。切块快照、联合对比、E01 状态均可读；移动端通知按钮与状态标签的遮挡已修复，实测水平交叠从 12px 降为 0，页面无横向溢出。
- 浏览器控制台没有 error/warn；Chrome 仍报告表单 label/id 的两类可访问性 issue，未影响本轮 RAG 工作流。

## 决策

不推广 `auto` 到正式知识库，原因如下：

1. 总体 Recall@20 没有提升，英语唯一未命中案例仍未恢复。
2. 2026 数学 DOCX 的 MRR 明显下降。
3. 文本块总数增加 4.6%，联合运行平均耗时增加约 7.4%，没有对应 Recall 收益。
4. 计划中的 MRR、结构化解析和答案覆盖推广门槛未满足；后两项还受本轮评测数据边界限制。

下一轮应先修复隔离副本的题组/chunk 关联重建，并把答案短语金标补入同一案例集；之后再针对英语表格和 2026 DOCX 排名下降案例，比较显式 `heading` / `heuristic` 与局部考试边界规则，而不是修改全局默认策略。
