## 验收中发现并修复的问题

首次进入聊天页时，情境引导曾产生 Vue I18n `SyntaxError: 10`。根因是四种语言的知识库/聊天引导文案把字面量 `@` 写成 Vue I18n linked-message 起始符。

- 新增 `frontend/src/i18n/contextualGuideMessages.test.ts`，递归编译四种语言的全部情境引导文案。
- 修复前定向测试稳定报告 8 个字段的 `Invalid linked format`；修复后 1/1 通过。
- 仅将 8 处字面量改为 Vue I18n 支持的 `{'@'}`，未调整引导结构或业务行为。
- 重建 frontend 后，专用 AI 讲解诊断输出 `[]`；完整三角色复验中 API failure、console error、page error 仍全部为 0。

原始“AI 讲解内容不完整”在真实错题样本上未复现：当前预填内容完整，实际发现并关闭的是聊天页情境引导的控制台错误。
