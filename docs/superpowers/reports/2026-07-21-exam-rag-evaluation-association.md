# 考试 RAG 评测动态关联验收报告

**日期：** 2026-07-21
**范围：** 25 条英语/数学联合评测案例
**结论：** 评测副本动态关联达到验收目标；暂不据此推广 `auto` 切块到正式知识库。

## 实现边界

- 正式 Chunk ID 关联仍优先；动态关联只在 `EvalResolver` 中启用。
- 全流程只读，不写正式题库、正式知识库或 `question_chunk_refs`。
- 评测短语先定位同 `file_hash` 的来源文件，再在该文件关联题库中使用 query、题号和题干唯一判定。
- 历史题组可能缺少题目级 Chunk 引用，因此候选收敛允许文件级回退；歧义候选仍拒绝。

## 剩余缺口

- E01 是真实召回缺口，需单独优化英语赛事表格的切块或排序。
- M25-05、M25-06、M25-08 的正式答案/解析仅保存图片 URI。关联已正确，但缺少可检索文本答案，后续应做答案图片 OCR 或人工结构化。
- `auto` 相比 `legacy` 没有提升 Recall@20，且本轮目标是修复评测关联，不改变原 A/B 报告“不推广 auto”的决策。
