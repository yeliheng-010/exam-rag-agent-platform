# 班级学习诊断 Agent 设计

## 目标

在现有班级练习统计之上提供教师可调用的 `exam_class_diagnosis` Agent 工具，让班主任和助教可以用自然语言获取班级完成情况、正确率趋势、高频错题和需关注学生，并继续结合 `exam_question_context` 获取完整题目材料。

## 方案选择

采用“统计服务负责可信聚合，Agent 工具负责紧凑表达”的方案：

1. `ExamAnalyticsService` 继续作为班级数据和权限的唯一入口。
2. `ExamPracticeRepository` 批量读取每个学生在每项任务的最新作答答案，避免逐学生逐题查询。
3. 统计服务按 `question_id` 聚合答题数、错误数、错误率和受影响学生数。
4. Agent 工具只格式化已经聚合的数据，并确定趋势方向和需关注学生，不直接查询数据库。

不采用工具直接拼接 repository 的方案，因为这会复制班级权限判断，也会让 Agent 层承担业务聚合职责。

## 权限与隐私

- 工具从会话上下文读取 `tenant_id` 和 `user_id`，不接受调用方伪造用户身份。
- `ExamAnalyticsService` 校验调用者必须是目标班级的 active `teacher` 或 `assistant`。
- 学生、待审核成员和非班级成员统一返回权限错误。
- 默认只向模型提供班级聚合、高频错题和最多 10 名需关注学生，不输出全班逐题明细。
- 所有 repository 查询必须同时带 `tenant_id` 和班级派生的 attempt 范围。

## 工具输入

`exam_class_diagnosis` 接受：

- `class_id`：可选。指定后直接诊断目标班级。
- `top_wrong_questions`：可选，范围 1-20，默认 10。
- `at_risk_students`：可选，范围 1-20，默认 10。

未提供 `class_id` 时，工具列出当前用户可分析的班级；如果只有一个班级则直接诊断，多个班级时返回班级 ID 和名称供 Agent 再次调用。

## 统计口径

### 基础指标

复用现有 `ExamClassAnalyticsSummary`：学生数、任务数、开始数、完成数、完成率、平均正确率、学生统计和任务统计。

### 高频错题

- 每项任务每名学生只使用最新一次 attempt。
- 对这些 attempt 的全部答案按 `question_id` 聚合。
- 输出题号、题干、答题数、错误数、错误率和受影响学生数。
- 仅返回错误数大于 0 的题目，按错误数、错误率、题号降序排列，最多保留 20 条。

### 掌握趋势

- 按任务创建时间从旧到新排列有作答的任务。
- 少于 2 个有效任务时为 `insufficient_data`。
- 比较前半段与后半段任务的平均正确率；差值不小于 5 个百分点为 `improving`，不大于 -5 个百分点为 `declining`，否则为 `stable`。

### 需关注学生

满足任一条件即进入候选：有任务但从未开始、完成率低于 50%、已有作答且平均正确率低于 60%。排序优先级为未开始、低完成率、低正确率，输出人数受工具参数限制。

## 输出结构

工具输出 XML 风格的紧凑上下文：

- `<class_summary>`：班级总体指标。
- `<mastery_trend>`：趋势方向和按任务的时间点。
- `<frequent_wrong_questions>`：高频错题聚合。
- `<at_risk_students>`：需关注学生和原因。
- `<diagnosis_instruction>`：要求模型基于证据生成教学建议；需要原题时调用 `exam_question_context`。

`ToolResult.Data` 同时保留结构化字段，便于未来前端做专用诊断卡片。

## 错误处理

- 缺少 tenant/user context：失败，不执行查询。
- 班级不存在或越租户：返回 not found/permission denied，不泄露班级存在性细节给模型。
- 没有可分析班级：返回成功的空选择上下文。
- 班级没有任务或作答：返回成功的空统计，不让模型臆测学习问题。

## 验证标准

1. 教师和助教能获取自己班级的诊断，学生被拒绝。
2. 未指定班级时能列出可分析班级，唯一班级可自动进入诊断。
3. 高频错题只统计每项任务每名学生的最新 attempt，并正确计算错误率。
4. 工具输出包含基础指标、趋势、高频错题、需关注学生和结构化 `Data`。
5. 工具在无知识库绑定时仍可使用；需要完整原题时再组合 `exam_question_context`。
