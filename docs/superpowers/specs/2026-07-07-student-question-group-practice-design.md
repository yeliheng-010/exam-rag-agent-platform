# 学生端题组练习与 AI 讲解设计

## 背景

考试平台已经完成班级空间、老师申请、资料入库、试卷结构化、题组草稿校对和正式题库展示。当前学生端仍以班级知识库对话为主，学生可以读老师授权的知识库，但不能围绕正式题组进行做题、判分和复习。

题组结构化解决了「试卷内容能不能正确沉淀」的问题，学生练习模块解决「沉淀后的题组能不能被真实使用」的问题。第一阶段只处理正式题库中的客观题练习，不进入作业发布、错题本、作文批改和学情分析，避免过早把教学运营流程绑死。

## 设计目标

- 学生可以在学习中心看到自己可访问班级空间中的正式题组。
- 学生可以进入题组练习页，按大题材料和小题顺序做题。
- 系统记录学生一次练习 attempt 以及每道题提交的答案。
- 客观题提交后立即返回是否正确、正确答案、解析和来源证据。
- 学生可以把当前题组和当前题目的上下文带入基础 RAG 对话，请 AI 讲解。
- 班级空间、租户、学生身份和老师题库管理权限继续隔离。

## 非目标

- 不开放学生访问题库管理中心。
- 不让学生访问题组草稿、模型原始输出或老师校对痕迹。
- 不实现作业发布、截止时间、批量布置和班级成绩统计。
- 不实现完整错题本、学习曲线和学情分析。
- 不实现主观题自动评分、作文批改和口语评分。
- 不给学生开放 Agent chat 或老师、管理员功能。

## 权限模型

第一阶段以 WeKnora 当前空间权限为底座：

- 学生是班级成员时，可以读班级空间中的正式题组。
- 学生不能写班级空间，不能创建题库、抽题、校对草稿或绑定知识库。
- 练习记录归属当前登录用户，用户只能读取和提交自己的 attempt。
- 题组练习接口使用 `Viewer` 路由守卫，再在服务层校验 `spaceService.CanReadSpace`。

这个模型和现有 `exam/question-banks/:bank_id/question-groups` 的 viewer 读取能力一致，但新增学生专用列表入口，避免学生必须知道题库 ID。

## 数据模型

### `exam_practice_attempts`

表示一次学生练习会话。

| 字段 | 说明 |
| --- | --- |
| `id` | attempt ID |
| `tenant_id` | 租户隔离 |
| `user_id` | 学生用户 ID |
| `space_id` | 题组所属空间 |
| `question_bank_id` | 所属题库 |
| `group_id` | 练习题组 |
| `status` | `in_progress` 或 `completed` |
| `question_count` | 本次题组题量 |
| `answered_count` | 已提交答案数量 |
| `correct_count` | 正确数量 |
| `started_at` | 开始时间 |
| `completed_at` | 完成时间 |
| `created_at` / `updated_at` | 时间字段 |

### `exam_practice_answers`

表示一次 attempt 下的一道题答案。

| 字段 | 说明 |
| --- | --- |
| `id` | answer ID |
| `tenant_id` | 租户隔离 |
| `attempt_id` | 所属 attempt |
| `question_id` | 正式题目 ID |
| `question_no` | 原卷题号快照 |
| `answer_text` | 学生提交答案 |
| `is_correct` | 是否正确 |
| `correct_answer` | 正确答案快照 |
| `question_snapshot` | 题干、选项、元数据快照 |
| `answer_snapshot` | 标准答案快照 |
| `explanation_snapshot` | 解析快照 |
| `answered_at` | 答题时间 |
| `created_at` / `updated_at` | 时间字段 |

答案表对 `(attempt_id, question_id)` 建唯一约束，学生重复提交同一题时更新答案而不是插入多条记录。

## 后端接口

### 学生可练题组列表

`GET /api/v1/exam/practice/question-groups`

查询参数：

- `space_id`：可选，限制到某个班级空间。
- `domain_id`：可选，限制考试域。
- `subject_id`：可选，限制科目。

返回：

- 题组基础信息。
- 所属题库名称。
- 题目数量。
- 最近一次 attempt 摘要。

服务层会解析当前用户可读空间，然后只返回正式、未删除题组。

### 获取练习题组详情

`GET /api/v1/exam/practice/question-groups/:group_id`

返回正式 `QuestionGroupDetail`，包含材料、资产、小题、选项、答案、解析和 chunk 引用。第一阶段前端会在提交前隐藏答案和解析，但后端仍返回完整结构，后续可以增加「练习视图 DTO」进一步裁剪。

### 创建练习 attempt

`POST /api/v1/exam/practice/question-groups/:group_id/attempts`

行为：

- 校验题组可读。
- 创建 `in_progress` attempt。
- `question_count` 来自题组正式小题数量。

### 提交单题答案

`POST /api/v1/exam/practice/attempts/:attempt_id/answers`

请求：

```json
{
  "question_id": "question-id",
  "answer_text": "B"
}
```

返回：

- 学生答案。
- 是否正确。
- 正确答案。
- 解析。
- 证据 chunk 引用。
- attempt 当前统计。

客观题判分使用规范化比较：去空格、转大写，并支持逗号、顿号、分号、斜杠分隔的多答案。

### 完成 attempt

`POST /api/v1/exam/practice/attempts/:attempt_id/complete`

行为：

- 校验 attempt 属于当前用户。
- 更新状态为 `completed`。
- 返回最终统计。

## 前端设计

### 学习中心入口

学习中心新增「题组练习」区域，对所有 viewer 可见：

- 展示可练题组数量。
- 展示最近 6 个可练题组。
- 每个卡片展示题组标题、题库、题量、最近练习进度。
- 点击「开始练习」进入练习页。

老师和管理员仍然可以从题库中心进入管理页；学生只看到练习入口。

### 题组练习页

练习页保持 TDesign 工作台风格：

- 顶部：返回学习中心、题组标题、题库名称、练习进度。
- 左侧或上方：题组材料，长材料默认折叠，可展开全文。
- 中部：一道题一个练习卡片，保留上一题/下一题和题号 tabs。
- 选项：客观题使用单选式选项按钮；非客观题第一阶段显示为文本答案输入。
- 提交后：展示正确/错误状态、正确答案、解析和来源证据。
- 操作区：提交答案、AI 讲解、完成练习。

### AI 讲解入口

第一阶段不开放学生 Agent chat，使用基础 RAG 对话：

1. 练习页根据当前题组材料、题干、选项、学生答案、正确答案和解析生成一段讲解请求。
2. 如果当前班级有知识库资源，优先选择同空间的知识库。
3. 调用 `menuStore.setPrefillQuery()` 把讲解请求预填到 `/platform/creatChat`。
4. 学生在对话页可以直接发送，也可以修改问题。

这样不需要改聊天底层，也不需要突破现有学生 RBAC。

## 与后续模块的关系

本阶段的数据结构直接支撑后续能力：

- 错题本：从 `exam_practice_answers.is_correct=false` 聚合。
- 作业发布：新增 assignment 表后关联 `question_group_id`，复用 attempt 和 answer。
- 学情分析：按班级、题组、题型、知识点统计 attempt 和 answer。
- 主观题评分：在 answer 表增加评分字段和模型评语，不影响客观题链路。

## 验收标准

- 学生账号能在学习中心看到班级空间中的正式题组练习入口。
- 学生账号不能进入 `/platform/question-banks` 管理页。
- 学生可以打开一个阅读题组，看到阅读原文、题干和选项。
- 学生提交客观题答案后，可以看到正确/错误、正确答案和解析。
- 学生可以切换上一题、下一题，并完成练习。
- 练习记录写入数据库，并且同一用户只能访问自己的 attempt。
- AI 讲解按钮能把当前题上下文预填到基础对话页。
- 老师、管理员现有题库管理和题组展示不受影响。

## 风险与控制

- **答案格式不统一：** 第一阶段只做客观题规范化比较，主观题标为未自动判分。
- **学生看到答案过早：** 前端只在提交后展示答案；后端第一阶段返回完整结构，后续可以拆出学生专用 DTO。
- **练习列表过大：** 首版按创建时间返回最近题组，后续增加分页和筛选。
- **AI 讲解选错知识库：** 首版优先选择同空间班级知识库，找不到时只预填上下文，不强行选择知识库。
- **数据扩展冲突：** attempt/answer 表保持通用，不绑定作业发布，后续可通过外键扩展。
